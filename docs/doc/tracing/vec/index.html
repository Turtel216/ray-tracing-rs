Module vec 

Source
Expand description

A 3-dimensional vector module utilizing SIMD for performance.

This module provides the Vec3 struct, which represents a 3D vector or point. It leverages std::simd::f32x4 to perform vector operations in a more efficient, parallelized manner. Common vector operations like addition, subtraction, dot product, cross product, and normalization are provided.

A type alias Point3 is also available for geometric clarity when a Vec3 is used to represent a point in space.
